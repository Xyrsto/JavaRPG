JavaRPG game server

The game server is running, but the web client is not built into this server, so there is no game page to show yet.

Build the web client into the server

You need Node 22 and Maven. From the repository root:

mvn -q -Pweb -pl server -am package -DskipTests

Then start the packaged server and open this address again. To work on the client with live reload instead, run npm ci and then npm run dev in the web folder while this server is running.

In the meantime

  • Try the game API in your browser (this server's interactive documentation).
  • Read the written documentation (quick start, concepts and the API reference).
  • Check the server health.
